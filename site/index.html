Ms. Pac-Man Neuron Microscope

Every alive fc neuron (active on ≥ 0.1% of steps) of a deep RL agent that learned Atari Ms. Pac-Man from game reward only (Sample Factory APPO, 2B emulator frames ≈ 500M agent steps, no imitation learning), audited Goodfire-style: top-activating frames, a ground-truth label from the console RAM, the neuron's vote on each action, and causal steering tests. Method, preregistration and code: GitHub repository.

fc neurons

Label = the single ground-truth feature that best predicts the neuron (R² of bin means with ≤ 20 bins per feature, fitted on even discovery games and scored on odd ones). "One job" = all features together explain ≥ 30% of its variance and the best single feature explains ≥ 70% of that. Labels are correlational; only the steering section makes causal claims.

conv3 channels

Within-cell AUROC: how well each channel's activation at a 7×7 position detects an object in the central 16×16-pixel core of that position's 36×36-pixel receptive field, averaged over positions weighted by how often the object is there (0.5 = chance; location is controlled by comparing only within a cell).
